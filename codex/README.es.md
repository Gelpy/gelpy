# Enrutador de memoria Codex - gelpy

Usa este enrutador después de `AGENTS.md`. Lee solo lo que corresponda a la tarea.

| Tipo de tarea | Leer |
|---------------|------|
| Ejecución de un Work Item | `gelpy-architecture/specs\<spec>\tasks.md`, `gelpy-track-work-item` |
| Demostrar criterios de aceptación | `gelpy-verify-work-item` |
| Decisión de release o no-release | `gelpy-release-version` |
| Cualquier cambio visual | `BRAND.md`, `gelpy-apply-brand` |
| Coordinación entre repos | `gelpy-orchestrate-agents` |
| Actualización de memoria | `gelpy-update-docs` |

Las skills viven en `gelpy-architecture/codex\skills`.
